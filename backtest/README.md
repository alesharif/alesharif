# Backtest — Real Bot v3.27 (Binance, 2025)

محاكاة تاريخية تعيد تنفيذ منطق استراتيجية البوت (مسار Binance النشط) على بيانات
2025 الحقيقية، باستخدام مرايا Binance العامة (`data.binance.vision` /
`data-api.binance.vision`) لأن `api.binance.com` محظور جغرافياً.

## التشغيل
```bash
pip install numpy pandas pyarrow matplotlib
# تجربة سريعة (15 عملة):
python3 -m backtest.run --capital 5000 --year 2025 --max-symbols 15
# التشغيل الكامل (كل أزواج USDT الحالية):
python3 -m backtest.run --capital 5000 --year 2025
# التحقق من تطابق دالة الإشارة:
python3 -m backtest.validate
```

## الملفات
- `strategy_core.py` — نسخة دقيقة من دوال الاستراتيجية النقية (مصدر الحقيقة للمنطق).
- `data.py` — تنزيل/تخزين شموع Binance (ZIP شهري + REST mirror).
- `engine.py` — محرك المحاكاة (مسح كل 4h، إدارة خروج كل 15m).
- `report.py` — الإحصائيات والمخرجات (CSV + PNG + ملخص).
- `validate.py` — إثبات تكافؤ المؤشرات المحسوبة مسبقاً مع `calc_signals`.

## الاستراتيجية المُحاكاة (الإعدادات النشطة)
v3 divergence (MACD+RSI+OBV على 4h) + فلاتر: الحجم ($1.5M)، OBV (#47)،
A+D اليومي (#48)، F3 (#51)، EMA99 (#20)، نسبة الحجم (#49). تحجيم بقانون الجذر
التربيعي، 5 صفقات كحد أقصى، SL −4% / Trailing +3% / Smart TP +15% / حد 24h،
cooldown هرمي. (فلاتر BTC و v4 و Early-Exit معطّلة كما في الكود.)

## انحرافات النمذجة الموثّقة
1. **انحياز الناجين**: نستخدم أزواج USDT الحالية فقط؛ العملات المشطوبة قبل اليوم
   غير مُمثّلة → النتائج متفائلة قليلاً.
2. **فلاتر Delisting/Monitoring**: حالات حيّة بلا سجل تاريخي → مُعطّلة في المحاكاة.
3. **دقة الخروج 15m** بدل polling كل 10 ثوانٍ؛ افتراض ترتيب داخل الشمعة معاكِس
   (الأدنى قبل الأعلى) لخروج محافظ.
4. **شمعة نسبة الحجم**: نقيس حجم شمعة الإشارة المغلقة مقابل متوسط 20 سابقة (نيّة
   الفلتر)، بدل الشمعة الجارية في النسخة الحيّة.
5. **مؤشرات يومية** تُحسب على أيام مغلقة فقط (EMA99/sigma يشملان اليوم الجزئي في
   النسخة الحيّة) — فرق ضئيل.
6. مؤشرات 4h محسوبة على كامل السلسلة (ewm متقارب) — تطابق `calc_signals` بنسبة
   99.97% (تحقّق `validate.py`).
7. التنفيذ عند إغلاق الشمعة بلا نموذج انزلاق (كما يفترض البوت).
