# Binance Strategy Simulator (محاكي استراتيجيات بينانس)

إطار عمل بايثون لمحاكاة استراتيجيات التداول على سوق **Binance Spot**، يدعم:

- **Backtesting** — اختبار الاستراتيجية على بيانات الشموع التاريخية لقياس الأداء.
- **Paper Trading** — محاكاة لحظية بأموال وهمية على بيانات السوق الحية (عبر سحب الشموع من واجهة بينانس العامة).
- **إطار استراتيجيات مرن** — أضف أي استراتيجية بوراثة كلاس واحد وإرجاع إشارة `BUY/SELL/HOLD`.

النواة تعتمد فقط على مكتبة `requests` (المؤشرات الفنية مكتوبة بـ Python نقي)، فلا حاجة لمكتبات ثقيلة.

---

## ⚠️ تنبيه مهم

هذا المشروع **للمحاكاة والتعلم فقط**. لا يقوم بأي تداول حقيقي ولا يرسل أوامر بأموال حقيقية.
- جلب البيانات يستخدم واجهة بينانس **العامة** (لا يحتاج مفاتيح API).
- التداول الوهمي (Paper) يحاكي المحفظة محلياً على بيانات الأسعار الحية.
- التداول بالعملات الرقمية ينطوي على مخاطر عالية. لا شيء هنا نصيحة مالية.

## الاستخدام السريع

### 1) اختبار تاريخي (Backtest)

```bash
python -m binance_sim backtest \
  --symbol BTCUSDT --interval 1h --limit 1000 \
  --strategy ma_crossover --params '{"fast":20,"slow":50}' \
  --cash 10000 --fee 0.001
```

### 2) محاكاة لحظية (Paper Trading)

```bash
python -m binance_sim paper \
  --symbol BTCUSDT --interval 1m \
  --strategy rsi --params '{"period":14,"low":30,"high":70}' \
  --cash 10000 --fee 0.001 --state state.json
```

يحفظ الحالة في `state.json` ليُستأنف بعد التوقف (مفيد في البيئات المؤقتة).

### 3) قائمة الاستراتيجيات المتاحة

```bash
python -m binance_sim list
```

## كتابة استراتيجية جديدة

أنشئ ملفاً في `binance_sim/strategies/` يرث من `Strategy`:

```python
from binance_sim.strategy import Strategy, Signal
from binance_sim.indicators import ema

class MyStrategy(Strategy):
    name = "my_strategy"

    def __init__(self, period: int = 21):
        self.period = period

    @property
    def warmup(self) -> int:
        # عدد الشموع المطلوبة قبل أن تنتج الاستراتيجية إشارة موثوقة
        return self.period + 1

    def generate_signal(self, candles) -> Signal:
        closes = [c.close for c in candles]
        line = ema(closes, self.period)
        if closes[-1] > line[-1]:
            return Signal.BUY
        if closes[-1] < line[-1]:
            return Signal.SELL
        return Signal.HOLD
```

ثم سجّلها في `binance_sim/strategies/__init__.py`.

كل استراتيجية تستقبل **كامل تاريخ الشموع حتى الشمعة المغلقة الحالية** وتُرجع إشارة واحدة.
المحرك يتكفّل بإدارة المحفظة، الرسوم، وحجم الصفقة.

## 🤖 باكتست استراتيجية "paper_bot_v2" (المحفظة متعددة العملات)

استراتيجيتك الخاصة (إطار 4h، طويل فقط، عبر كل أزواج USDT) مدمجة كمحرك باكتست
مخصّص يحاكي منطقها بالضبط: إشارة الدخول + وقف ATR المتحرك + محفظة 8 صفقات متزامنة
بحجم 12.5% لكل صفقة ورسوم 0.2%.

```bash
# باكتست على كل العملات السائلة (الأسرع: حدّد عدد العملات)
python -m binance_sim.portfolio_backtest --start 2024-01-01 --max-symbols 120 --out results

# باكتست على عملات محددة
python -m binance_sim.portfolio_backtest --start 2024-01-01 --end 2024-07-01 \
    --symbols BTCUSDT,ETHUSDT,SOLUSDT --out results

# كل الكون (~430 عملة) — أبطأ في الجلب
python -m binance_sim.portfolio_backtest --start 2023-01-01 --out results
```

**منطق الاستراتيجية** منقول حرفياً في `binance_sim/paper_bot_strategy.py` (نفس المؤشرات
ودالة الإشارة)، بدون أي كود شبكة أو مفاتيح. مصدر البيانات هو مرآة بينانس العامة
`data-api.binance.vision` (لا تحتاج مفاتيح، ولا تتأثر بالحجب الجغرافي).

### ⚠️ دقّة الباكتست (Backtest fidelity) — اقرأ هذا

1. **انحياز الناجين (Survivorship bias):** الكون يُبنى من العملات المُدرَجة *اليوم*،
   فالعملات التي حُذفت من بينانس غائبة. هذا يجعل النتائج **متفائلة** مقارنة بالواقع.
   (ملاحظة: تعليق الكود الأصلي يذكر أنه "يحسم الناجين" عبر التداول الحي — وهذا صحيح
   للايف، لكن أي باكتست تاريخي على القائمة الحالية يعيد إدخال هذا الانحياز).
2. **محاكاة الخروج:** البوت الحي يراقب السعر كل 30 ثانية، بينما الباكتست يملك شموع
   4h فقط. نموذج الخروج: نرفع الوقف المتحرك باستخدام أعلى سعر الشمعة (high) ثم نتحقق
   إن لمس أدنى السعر (low) مستوى الوقف → خروج عند سعر الوقف. هذا تقريب معقول لكنه
   **متفائل قليلاً** في الصفقات المتحركة.
3. **حجم/سيولة point-in-time** محسوب من بيانات كل عملة نفسها (آمن زمنياً)، لكن فلتر
   المستقرة يُحتسب تاريخياً من 4 أزواج مستقرة وقد لا يطابق ما رآه البوت لحظياً.
4. **MAX_HOLD=60** معرّف في كودك لكنه **غير مُفعّل** في حلقة البوت الحي، فهو معطّل
   افتراضياً هنا (فعّله بـ `--max-hold 60` للتجربة).

### المخرجات

- ملخّص في الطرفية: العائد، مقارنة BTC، أقصى تراجع، عدد الصفقات، نسبة الربح،
  معامل الربح (Profit Factor)، وتوزيع أسباب الخروج (SL/TRAIL).
- مع `--out DIR`: ملفّا `trades.csv` (كل صفقة) و`equity.csv` (منحنى رأس المال).

### 🎯 كون نقطة-زمنية (إزالة انحياز الناجين) — `--source archive`

افتراضياً يبني الباكتست الكون من العملات المُدرَجة **اليوم** عبر الـ API، وهذا
**يعيد إدخال انحياز الناجين** (العملات المحذوفة غائبة). الحل:

```bash
python -m binance_sim.portfolio_backtest --source archive \
    --start 2022-01-01 --end 2025-12-31 --vol-sizing --out results_pit
```

`--source archive` يبني الكون والبيانات من أرشيف `data.binance.vision` الذي يحتفظ
بشموع **العملات المحذوفة** طوال فترة تداولها الحقيقية (FTT, SRM, LUNA القديمة، ...).
الوحدة `pit_universe.py` تسرد كل عملة USDT وُجدت يوماً (589 مقابل 412 حيّة اليوم)،
تنزّل الشموع الشهرية بالتوازي مع تخزين مؤقت، وتطبّع طوابع الوقت بالميكروثانية (2025+).
عند حذف عملة وأنت داخل صفقة، تُغلق الصفقة عند آخر سعر متاح (خروج `DELIST`).

هذا يعطي **الرقم القابل للتصديق** — والفرق بينه وبين وضع الـ API يقيس حجم الانحياز.

### بارامترات الواقعية

| البارامتر | الأثر |
|---|---|
| `--slippage 0.10` | تكلفة انزلاق إضافية على الرسوم (تعبئة غير مثالية) |
| `--fixed-notional` | حجم ثابت بدل التركيب — يعزل الحافة الحقيقية للصفقة |
| `--exit-model pessimistic` | يفترض أسوأ مسار داخل الشمعة (حدّ أدنى) |
| `--vol-sizing` | تحجيم بـ 0.1% من فوليوم العملة بعد عتبة `--vol-threshold` |

## المقاييس المحسوبة في الاختبار التاريخي

- العائد الكلي ومقارنته بـ Buy & Hold
- عدد الصفقات ونسبة الرابحة منها (Win rate)
- أقصى تراجع (Max Drawdown)
- نسبة شارب التقريبية (Sharpe)
